# Dusa Solutions — Plan de Contenido

Panel del plan de contenido de Instagram/Facebook de Dusa (octubre 2026: estudio de apps hechas para México).
Pensado para el celular: "Lo que sigue", calendario del mes y cada post con sus imágenes a tamaño Instagram
para **compartir directo a Instagram** (o descargar), el texto para copiar y su estado (en cola · programado · publicado,
guardado en el navegador).

Ver: **https://mdusa11.github.io/dusa-plan/**

Se genera con `agencia/contenido/posts/_fuente/build_panel.py` (plantilla `panel_template.html`): no editar
`index.html` ni `img/` a mano. `?hoy=2026-10-07` en la URL simula otra fecha.
